# Security

Report security issues privately to the project maintainer.

Do not open public issues containing:

- secrets, cookies, tokens, or browser profile data,
- exported council transcripts with sensitive content,
- provider account/session details,
- bypasses that allow automation on origins outside the declared host permissions.

## Scope

In scope:

- extension permission misuse,
- unintended transcript export or storage,
- cross-provider prompt sharing that is not disclosed,
- automation on origins not chosen by the user,
- content-script overcollection from supported provider pages.

Out of scope:

- behavior of third-party AI providers,
- provider model outputs,
- provider account limits or moderation decisions.
