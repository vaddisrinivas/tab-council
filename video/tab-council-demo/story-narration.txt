Tab Council is an extension-based Model Council.

Create a Chrome tab group named tab-council. Put ChatGPT, Claude, Gemini, Perplexity, and Grok inside it.

Those tabs become council seats.

There are extensions that ask many AIs at once. This runs a council.

Assign roles: Member, Judge, Validator, Observer, or Exclude.

Round one asks every member for an independent answer. Round two shares the answers and asks for polite critique. If disagreement remains, Round three asks for final positions.

Structured JSON keeps the side panel reliable. JSON repair fixes almost-valid model output. The judge writes a verdict table with agreement, disagreement, confidence, and reasoning trace.

Then Ratify or Veto lets validators challenge the final answer before you trust it.

No new API account. No backend. Runs in your logged-in tabs, stored locally in Chrome.
